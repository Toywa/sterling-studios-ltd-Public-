## Deploy to Vercel (recommended)
1. Push this folder to GitHub: sterling-studios-ltd
2. Go to vercel.com → Add New → Project → Import your repo
3. Framework: Vite, Build command: npm run build, Output: dist
4. Add domain: sterlingstudios.com in Vercel → Settings → Domains
5. Add email DNS if needed, then deploy

## Vercel CLI alternative
npm i -g vercel
vercel
vercel --prod --domain sterlingstudios.com
